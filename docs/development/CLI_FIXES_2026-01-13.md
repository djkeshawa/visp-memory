## Issues Fixed

### 1. ✅ Default Backend Changed from Neo4j to SQLite

**Problem**: First-time users experienced immediate crash when running `llm-memory init`

```bash
$ llm-memory init --type code
Failed to initialize Neo4j driver: {neo4j_code: Neo.ClientError.Security.Unauthorized}
```

**Root Cause**:
- Default backend was `neo4j` in `config.py:34`
- Required Neo4j server running locally
- No fallback or helpful error message

**Fix**:
```python
# Before
backend: Literal["sqlite", "neo4j"] = "neo4j"

# After
backend: Literal["sqlite", "neo4j"] = "sqlite"
```

**Impact**: Users can now run `llm-memory init` without any external dependencies

**Files Changed**:

### 4. ✅ Dedup Command Numpy Array Comparison Error

**Problem**: `dedup` command crashed with ValueError

```bash
$ llm-memory dedup --layer episodic
ValueError: The truth value of an array with more than one element is ambiguous.
Use a.any() or a.all()
```

**Root Cause**:
- Line 132: `if not data["embeddings"]:` doesn't work with numpy arrays
- Line 161: `sim_matrix[i][j]` uses list-style indexing instead of numpy 2D indexing

**Fix**:
```python
# dedup.py:132-134 (before)
if not data or not data["embeddings"]:
    return []

# dedup.py:132-134 (after)
if not data or data.get("embeddings") is None or len(data.get("embeddings", [])) == 0:
    return []

# dedup.py:161-163 (before)
if sim_matrix[i][j] >= threshold:

# dedup.py:161-163 (after)
similarity = float(sim_matrix[i, j]) if hasattr(sim_matrix[i, j], '__float__') else sim_matrix[i, j]
if similarity >= threshold:
```

**Why Tests Missed This**: Zero test coverage for dedup functionality

**Files Changed**:
- `src/llm_memory/quality/dedup.py:132-134`
- `src/llm_memory/quality/dedup.py:161-163`

### 5. ✅ Vector Search Returning Negative Similarity Scores

**Problem**: Similarity scores were negative or near-zero for good matches

```bash
$ llm-memory recall "authentication"
┃ Content                                  │ Score │
┃ Fixed authentication bug in login module │ -0.68 │  # Should be ~0.8+
┃ Use PostgreSQL for main database         │ -0.80 │
```

**Root Cause**:
- ChromaDB collections created without specifying distance metric
- Defaulted to L2 (Euclidean) distance instead of cosine similarity
- Formula `similarity = 1 - distance` doesn't work with L2 distances

**Fix**:
```python
# storage.py:389-393 (before)
self._collections[layer] = client.create_collection(
    name=f"memories_{layer}",
    metadata={"description": f"Memory embeddings for {layer} layer"}
)

# storage.py:389-393 (after)
self._collections[layer] = client.create_collection(
    name=f"memories_{layer}",
    metadata={
        "description": f"Memory embeddings for {layer} layer",
        "hnsw:space": "cosine"  # Use cosine distance for proper similarity scores
    }
)
```

**Results**:
- Before: Score -0.68 for "authentication" → "Fixed authentication bug"
- After: Score 0.53 for partial match, 0.23 for weak match (correct)

**Why Tests Missed This**: No tests validated actual similarity score values

**Files Changed**:
- `src/llm_memory/core/storage.py:389-394`

## Why Unit Tests Didn't Catch These Issues

### 1. **Abstraction Layer Mismatches**
- Unit tests called `Memory` class methods directly
- Parameter signature mismatches only surfaced through CLI → Memory → Storage chain
- No testing of interface compatibility between layers

### 2. **No End-to-End Testing**
- Tests created `Memory` instances programmatically
- Never exercised CLI entry points (`app`, command parsing)
- Typer CLI framework behavior not tested

### 3. **Mocked Dependencies**
- Some tests mocked storage layers
- Hid real interface issues between components

### 4. **No Default Configuration Testing**
- Tests always provided explicit configs
- Never tested default initialization path
- Missed the Neo4j default backend problem

### 5. **Missing Feature Coverage**
- Dedup: 0% coverage
- Vector search scoring: No validation tests
- Multi-repo parameters: Not tested with LocalStorage
